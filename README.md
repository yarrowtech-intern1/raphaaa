**Raphaaa** is a full-stack e-commerce platform built with the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. It provides a modern, responsive, and feature-rich online shopping experience with advanced admin and user functionalities.

---

## **Features**

### Frontend (React + Tailwind CSS)
- Responsive and modern UI
- Product catalog with categories, filters, and search
- Product details, image galleries, and variant selection (size, color)
- Shopping cart, wishlist, and previously viewed products
- Newsletter subscription and promotional alerts
- User account management and order tracking

### Backend (Node.js + Express + MongoDB)
- RESTful APIs for users, products, orders, and reviews
- Admin and custom roles (admin, merchandise, marketing, delivery boy)
- Order management with status updates
- Inventory and stock tracking with low-stock alerts
- Razorpay payment integration with webhook-based stock handling
- Review system for products including ratings and optional images
- OTP-based mobile and email verification
- Content management for pages like About Us, Hero section, Offers, and FAQs

### Additional Features
- Season-based product offers and promotional banners
- Collab showcase section with footballers and used products
- Marketing dashboard: campaign tracker, email marketing, coupon management, traffic analytics
- Fully customizable admin panel with modern UI design
- PDF invoice generation for orders
- Horizontally scrollable “New Arrivals” and “Exclusive Drop” sections

---

## **Tech Stack**
- **Frontend:** React.js, Tailwind CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication & Security:** JWT, OTP verification
- **Payment Gateway:** Razorpay
- **DevOps:** Git, GitHub
